## Projects

### Python Port Scanner

A network scanning tool developed in Python.

**Features:**
- Hostname and IP resolution.
- TCP port scanning (1–1024).
- Identification of common services.
- Banner grabbing.
- Multithreading with ThreadPoolExecutor.

### Cisco Packet Tracer

Network simulation exercises involving:

- Network topology creation.
- Router and switch configuration.
- IP addressing.
- Default gateway configuration.
- Communication between subnets.
- Connectivity tests using ping.

### VLSM & Subnetting

Practical exercises involving:

- Network address calculation.
- Subnet masks.
- Broadcast addresses.
- First and last usable IP addresses.
- Host capacity.
- Variable Length Subnet Mask (VLSM).

### Network Documentation

Technical notes about:

- IPv4 addressing.
- Network segmentation.
- Communication between subnets.
- Routers and default gateways.
